C++ Point and Click Game

Back

This project was a simple point and click game using C++ and SFML. This project was made for my University Year 2 C++ course. The game was a simple level by level puzzle game where the player would need to find/create a key to unlock the next level. The projects requirements where sparse in complexity comparative to previous projects. This allowed me to attempt the use of different coding practices and features for different puzzles. The requirements of the project were the following:
  • Must fall under the Point and Click category
  • Needs at least 2 rooms/levels
  • Ability to click, drag or interact with elements in the level using the mouse
  • A puzzle that needs to be solved to progress
  • Win Screen
  • Use of Smart Pointers and Vectors

As the requirements were broad in scope I was able to try new things. The main 2 additions I wanted to implement was some kind of lock picking puzzle, to do this I learnt the basics of tilemaps where the player must drag a key through a maze without touching the walls to "pick" the lock, and a crafting puzzle where the player would need to combine parts to create a key.

This project was an engaging experience, however I did feel the level of quality graphically let down the overall game. But I still learnt a range of essential new skills, such as smart pointers and vectors which I first ever implemented into this project.
