Maya Robot Model

Back

First assessment for university was to create this model to a specification. The specifications were the following:
  • Tri Limit of 1500
  • Must be a robot of variance
  • Must be made in Maya

The model could take inspiration from any source, so I chose to make a version of the Butter Robot from Rick and Morty. This was my first introduction into using Maya as a 3D modelling software. I had a lot of fun with this project, and it was a great introduction to the software. I would have liked to add more detail to the model, but I was limited by the tri count as the details I wanted to add would have required smoother topology.
