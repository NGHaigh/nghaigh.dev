C++ Top Down Game

Back

This is a top-down game project created using C++ using SFML. This project was made for my University Year 2 C++ course.

The game was created to cover a range of primary mechanics and requirements. These consisted of the following:

  • Player Movement
  • Interactable Objects
  • Collision Detection
  • Game State Management
  • TileMaps
  • Use of Smart Pointers and Vectors

This was a fun and insightful project, it provided me with a deeper understanding of how to code using Tilemaps and more sophisticated collision detection. The code provided a very good base for expansion and improvement. The only notable improvements that could be added would be full coded Pathfinding of either BFS or A*, and threading for code performance optimisation.
