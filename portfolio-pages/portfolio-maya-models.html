For my Pirate Island Environment Project, I was tasked to create 3 models to be scattered throughout the level that fit to theme. These models had a set of requirements which were the following:
  • Tri count limit of 1000
  • One model needed to be a drinks container
  • One model needed to be a fruit
  • One model needed to be a container
  • Must be themed to the environment

Using these specifications, I created a Pineapple, Glass Bottle and a Chest. These models were then scattered around the Pirate Island Environment project for level building
