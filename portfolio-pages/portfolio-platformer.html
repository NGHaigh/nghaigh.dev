C++ Platformer

Back

My first major coding project at university was this platformer. I created it as my final C++ project in year 1 of university. The specifications of the project were to create a platformer game that fit specific requirements. These consisted of:
  • Has to be a Platformer
  • Player Movement (Side Scrolling Left, Right and Jump)
  • Collision Detection (AABB)
  • Have hazards and collectibles
  • Include a scoring system
  • Win and Lose conditions

The project was a major test as it was might first true experience coding a game completely blind. All features I wanted to add were added, including power-ups to make the level more engaging, moving hazards that increased the difficulty, and a scoring system that allowed the player to collect coins and gain points.

This project taught me a lot about coding games, but primarily where I needed to improve as there were areas of inefficiency in the code that wasted much of my development time.
